## 使用

退出旧实例，重新运行 `emergence` 即可使用已构建的本地版本。

- 确认：方向键选择，Enter 提交当前高亮项，Esc 取消本次请求。允许本次、拒绝本次均有明确选项。y/n 和数字仍可用于定位选项，再按 Enter 提交。
- 多选：方向键移动，Space 勾选，再按 Enter 提交。
- 自定义回答：选中“自定义回答”，在独立输入区输入；Shift+Enter 换行。Esc 先返回选项，再按 Esc 取消请求。
- 后台窗口请求确认时显示待处理状态，不抢当前输入焦点。回答后恢复原聊天草稿和选区；结果跟随输出区显示。
- Ctrl+P 打开独立命令入口，可以在审批期间输入 `/focus 2` 切换窗口。它不占用聊天草稿。Esc 或 Ctrl+C 关闭命令入口。
- Ctrl+C 优先复制选区；否则关闭当前交互、清空聊天草稿或停止当前窗口任务。空闲时提示再按一次退出，第二次需要在 2 秒内按下。
- 若要保留当前草稿退出：Ctrl+P，然后输入 `/exit` 并按 Enter。重新打开后通过首页“继续工作台”恢复。

Ctrl+P 本阶段是命令输入入口；完整搜索、补全与历史检索仍在后续阶段。Shift+Tab 暂时保持原有窗口切换，不提前宣称已经支持执行模式。

## 实现与边界

- 新增结构化 InteractionQueue：请求 ID、版本、会话和 Agent 归属、种类、选项及状态。一次响应只能生效一次，过期或非队首响应被拒绝。
- 权限确认、单选、多选、文本回答分开表达。自定义文本 `1` 不会被误解成选项 1。旧 respond(text) 仅保留为兼容适配。
- UI 直接提交请求 ID 和结构化回答，不从提示文案推断授权；权限仍为单次，不添加会话级或永久授权。
- 取消、关闭窗口或更换会话会清理等待项；后台请求按实际运行时归属路由。
- 过滤终端上报的重复按键，对跨请求的快速 Enter 连发增加短暂保护；新输入或粘贴聊天任务会解除旧提交保护。审批界面的粘贴不会自动变成授权。
- 文本选区复制使用宿主剪贴板，失败时尝试终端 OSC52 并明确提示状态。

已在回归中修复：确认后重新聚焦时机、数字自定义答案误解、新输入被防连按误挡，以及长会话回答后看不到新结果的问题。
