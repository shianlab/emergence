## 发行收尾

发布前的 GitHub 干净环境检查发现两项差异：Windows 自动行尾转换使 JavaScript 格式检查失败；Windows 8.3 短路径被安装清理函数误判为目录跳转，影响失败恢复和旧版本清理。已补齐 JavaScript 行尾规则，并在唯一文件所有权模块中同时验证逻辑路径和真实路径归属，继续拒绝越界与链接。

短路径问题在本机真实 8.3 临时目录中复现；修正后，文件边界、事务回滚、进程中断恢复和清理共 23 项全部通过，没有跳过。新增回归同时确认安装根目录、外部目录及目录链接不能被删除。发行包重新生成清单、ZIP 与签名，安装器变化单独复验；原候选及原完整巡检记录保留，不能将用户对旧候选的反馈当成修改后安装器的外部验收。

另规范一处 C# 文件末尾多余空行，通过原生格式及严格编译检查。正式包更新 README 的候选措辞。程序载荷与原候选逐文件比较，允许的行为变化仅为上述安装清理修正。

执行顺序为：发布分支检查 → 不可变发行资产 → 匿名下载与安装核验 → 主分支及稳定清单 → 默认最新发行。不会先让客户端看到尚不存在的下载资产。

详细机器记录保存在忽略目录 `artifacts/publish-v1.0.2/`，不上传用户配置、密钥和实际会话。更新说明见 [1.02](releases/1.0.2.md)，完整候选矩阵见[第四阶段报告](installation-phase4-report-2026-11-17.md)。
