# 第三阶段：编排整理、安全回归与统一验收

日期：2026-10-31。范围：本机调试版本；不打安装包，不上传 GitHub，不改用户真实模型配置。

## 已修复与整理

1. **跨窗口依赖的审批计时遗漏**：手动派发到不同窗口时，前置任务等待审批，后续任务过去仍可能耗尽排队预算。现在沿直接和传递依赖识别审批等待，分别累计审批时间；拒绝后按依赖失败处理。新增三个工作窗口的实际 Harness 回归，验证等待期间没有写入、没有误超时，拒绝后依赖阻塞。
2. **职责拆分**：持久化任务结构、状态集合和标签集中到 `task-state.ts`；预算轮询与依赖计时移到 `task-budgets.ts`；`collaboration.ts` 保留唯一队列和生命周期协调。预算到期的异步收尾仍由原有任务集合跟踪，退出时等待完成。
3. **共同定义**：任务/规划/总任务的内部上限集中到 `run-budget.ts`，超时类型从校验结构导出；审查资源选择和总任务协调共享执行结束状态。`needs_review` 仍不等于验收成功。
4. **代码规范入口**：固定 Prettier 3.9.10，限定 18 个编排相关文件，增加 `check:style`、`format:orchestration` 和 `check`。没有整库格式化，也没有重做 TUI。维护约定见 [orchestration-maintenance.md](orchestration-maintenance.md)。
