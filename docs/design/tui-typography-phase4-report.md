# 文字层级第四阶段：适配与巡检

日期：2026-11-16。本轮检查原生文字方案的适配；第一阶段 B 版图形小字仍仅为独立试验，没有加入正式 TUI。

## 发现及修复

1. 英文共享项目详情在窄窗和窄分屏中超过固定四行，尾部被裁掉。改为由原生文字布局计算展开高度。32 组尺寸/主题/语言/展开状态组合验证后，详情均完整，输入区没有越界，中文与 emoji 草稿保留。
2. 底栏原先先拼路径与完整 Tokens 说明再整体截断；小窗可能截掉 Token 值。现在优先保留值、`≥` 和未返回的 `—`，不足时省略括号说明，再缩短目录。正常宽度仍保留完整说明。
3. 普通回执字典的原型属性可能误判同名未知通知（如 `constructor`），导致内容被隐藏。现在只匹配字典自身已知回执项；错误和未知通知仍持续显示。
4. 当前任务详情组件已删除 takeover 控件，但返回对象残留同名变量，实测工作台初始化抛出 ReferenceError。清除残留引用，保留另一窗口移除协作功能的新代码。

- `tests/tui-auxiliary.test.ts`：7 项通过，包含底栏宽度、Unicode、缺失/部分 Token 回执标记，以及回执过期、确认、错误、会话隔离。
- `tests/tui-typography.ts`：3 组通过，覆盖标题、引用、原始代码、窄屏与浅色主题。
- `tests/tui-phase1.ts`：11 项首页检查通过。
- `tests/tui-phase2.ts`：13 项消息检查通过。
- `tests/tui-phase3.ts`：14 项输入/状态检查通过。
- `tests/tui-aggregate.ts`：图形加载、资源释放、比例和不支持图形时的行为通过。
- `tests/tui-phase2-terminal.ts`：真实 ConPTY 7 项检查通过，包括缩放保留对话、加粗、原文与代码、退出恢复。
- `tests/tui-phase1-terminal.ts`：真实 ConPTY 首页 6 项检查通过。

矩阵证据位于 `artifacts/tui-typography-phase4/matrix.json`，同目录保存各组合的原生字符帧。这些不是操作系统窗口截图；没有把浏览器字体模拟当作终端验收。字体缩放通过终端行列尺寸变化覆盖重排，未逐一人工检查每种字体字面的栅格化或所有其他终端软件。

## 前后对照

| 场景 | 调整前 | 当前 |
| --- | --- | --- |
| 窄窗英文共享详情 | 固定高度裁掉末尾 | 原生自动高度，输入框仍在窗口内 |
| 窄窗 Token 底栏 | 长说明可能挤掉数值 | 保留数值与未知/部分标记，目录按宽度缩短 |
| 特殊同名通知 | 可能被当作已知回执 | 持续显示，只有明确列出的普通回执过期 |
| 标题、发言人和正文 | 主要靠灰阶 | 沿用第三阶段字重、段距、缩进及引用表面 |
