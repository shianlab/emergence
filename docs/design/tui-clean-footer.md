# 对话页底栏精简与 Token 用量

2026-10-30 按用户要求保留「独立模式」（各会话独立工作，尚未启用主控协作派发），移除常驻的发送、换行、切换、分屏等快捷键提示及底栏重复模型信息。输入、快捷键和弹出的操作菜单功能不变；确认面板内的操作引导仍保留。

「内置核心 · 已自动分流 · 直接回答」来自内部规划状态，已移出对话输入区常驻提示。没有关闭规划能力；详情仍可通过 `/plan` 与 `/core` 查看。错误、共享项目提醒和操作通知继续在输入区附近显示。

底栏只显示目录与本会话累计 Tokens：单窗口一行，分屏后每个窗口独立一行。读取 Harness 已结算的供应商 usage 回执，恢复历史时重建一次，随后按事件增量累计；包含有回执的失败尝试。输入缓存计数计入总量，推理计数不重复叠加到输出。数字不是上下文占用，也不是金额或整个工作台全部子 Agent 的汇总。

尚未请求模型时为 0；回执缺失时显示「未返回」，仅部分调用有回执时显示「≥…（部分）」。不会用字符数估算，也不会将未知值当作零。输出过程中通常在该次模型调用结算后更新。

验证覆盖用量求和、缓存、历史重放、去重、缺失回执、失败重试、会话隔离；输入区、分屏、焦点、缩放和真实 ConPTY 停止/退出回归通过。现有 `/statusbar off` 仍可隐藏底栏；旧 `fields` 配置保留兼容，但不再把模型/任务等字段加回简洁底栏。

实际组件预览：`artifacts/brand/volcano-native-preview.html`；其中 Token 数来自预览专用模拟供应商，仅用于验证展示。截图：`artifacts/brand/clean-footer-preview.png`。

扩大单元测试共 174 项，171 通过、3 失败。失败项：audit-security.test.ts 的子任务 exit code: 9 回执断言，以及 phase5.test.ts 的写入权限与扩展工具断言；后两项实际返回内置核心要求先完成目标分析。没有为使测试通过而修改规划/权限规则。失败明细见 artifacts/tui-footer-tests.log。本轮 3 项 Token 专项、12 项输入区原生回归、15 项工作台原生回归、11 项 ConPTY 输入回归与类型检查/构建均通过。
