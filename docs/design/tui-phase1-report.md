# 涌现 TUI 第一阶段记录

日期：2026-10-29。范围：首页、黑白灰主题、手写像素 Logo、首次提交后的会话切换。

## 已接入正式入口

普通运行 `emergence` 先显示独立首页。按用户本次调整，缩小的手写像素 Logo 居中靠上，下方是同为半块字符的像素英文 `EMERGENCE`；供应商、模型、项目、Git、角色与能力入口统一位于标识下方。120/160 列使用 56 列 × 11 行中文，80×24 使用 40 列 × 8 行中文；50×30 使用 48 列 × 10 行中文，50×20/40×18 退为文字品牌。中央内容最多 88 列，输入区与品牌同轴，不再让宽屏输入铺满整屏。

中文新增尺寸直接从原始透明母版按相同阈值采样，未重写字形或调整字间位置。本次细化改为每字符 2×2 象限块：保持 56/48/40 列的占屏大小，横向采样点翻倍为 112/96/80，按终端字符约 1:2 的宽高比保留原稿比例。英文为固定像素字母，38 列 × 3 行，与中文一起轻缓显现；原始母版和此前的像素尺寸继续保留。可通过 `emergence/scripts/build-home-brand.ps1` 重新生成这组终端字符资源。

输入框保留三行编辑空间，模型状态移到框外，与输入、快捷键、入口和退出提示分组留白。常规高度下各组之间空一行；较矮终端逐步合并提示行，优先保留输入和实际模型。预览由 `probes/home-preview.ts` 导出原生 OpenTUI 帧，而非单独手写网页布局，见 `artifacts/brand/home-centered-preview.html` 与 PNG 截图。

用户箭头标注的局部修正：48 列版本「现」字左侧偏旁的孤立突点，从采样网格 `(55,10)` 上移到 `(55,8)`（从零计数）。该修改在生成脚本中明确记录；核对结果为一格移出、一格移入，墨点总量、其他尺寸及英文均保持原样。原始透明母版保留。当前预览按截图对应的 50×30 终端尺寸导出；可运行 `probes/home-preview.ts 120 38` 查看宽屏尺寸。本次重新通过类型检查、构建与 9 项首页专项。

后续三个箭头按最新要求仅修正 48 列版：删除「涌」第一点下方短尾 `(11,3)`；第二处缺口 `(19..21,2)` 保持原来的留空，第三处字顶凸块 `(28..30,1)` 保留，并在其右侧增加 `(31..32,1)` 两列像素。前一次「现」字修正仍保留，56/40 列版、英文和透明母版未改。

用户后续标注的宽屏版本修正：删除 56 列「涌」字顶两个细小凸点 `(21,2)`、`(34,1)`。逐格核对仅这两格移除；48 列已确认的顶部凸块、40 列版本、英文与透明母版保持原样。

2026-10-30：按最后的箭头标注，删除 56 列「现」字左上横画的单个凸点 `(64,4)`；逐格核对仅移除这一格，其他像素、其他尺寸与原稿保持原样。

首页本身不创建 Agent、不请求模型，也不写工作台布局。提交新任务后创建新工作台，并通过同一提交入口发送第一条消息，快速重复 Enter 不会重复创建会话。首条消息发送失败时，正文编辑区保留该草稿。

首页可点击或输入 `/model` 选择下一会话模型，`/sessions` 选择历史，`/continue` 恢复上次工作台。显式 `--resume` 与 `--template` 直接进入目标工作台。新建前将原布局完整复制到 `workspaces/*.before-home-*.json`，历史会话保留。

默认深色主题改为黑白灰，浅色主题也使用中性灰阶；已有自定义颜色和其他主题配置继续保留。对话标题显示供应商与实际模型，底栏精简为发送、换行、停止、分屏与帮助；上下文容量不再伪装成已用量。

首页显现动画可被输入打断。`NO_COLOR`、`TERM=dumb` 或 `EMERGENCE_REDUCED_MOTION=1` 关闭动画。Logo 文本被编入构建结果，运行时不依赖开发目录中的图片素材。
