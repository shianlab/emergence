# 文字层级第二阶段：辅助信息区减重

2026-11-16。用户授权开始第二阶段。第一阶段 A/B 小字方向尚未明确选定，因此本轮使用可选择复制的原生文字，未接入图形小字，也未声称实现局部字号缩放。

## 行为

- 已提交、本轮已完成、新建和恢复会话等已知普通回执在空闲状态显示约 4 秒，由每秒刷新收起，之后恢复实际状态。执行、排队、确认和错误状态优先，提交回执不与它们争占位置。
- 不再在 notice 和状态行重复呈现完成回执；初次进入的输入提示由输入框承担，不额外占行。
- 同目录会话显示“共享项目 · 另有 N 个会话 · [详情]”；空闲时与就绪合并成一行。窄窗用短标签，点击展开协调说明，不改变当前会话或草稿；再次点击收起。
- 错误和确认保留正文级对比度及加粗。未知通知、真实冲突、命令结果不套用普通回执的定时消失规则；待确认时也不隐藏独立错误。
- 底栏继续显示目录和每个会话自己的实际 Tokens，保留既有未返回语义。

实现：`src/app/tui/auxiliary-info.ts` 仅生成显示状态；`workspace-ui.ts` 应用颜色、可见性、行高和详情交互。没有更改 Agent 执行、排队或协作调度逻辑。
