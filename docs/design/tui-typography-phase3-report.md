# 文字层级第三阶段：对话与章节

2026-11-16。用户授权开始第三阶段，已接入正式 TUI。继续使用原生文字，无局部字号缩放或正文图片化。

## 呈现规则

- 一级标题：加粗、较亮正文色、随标题宽度变化的短横线，最长 24 列；横线是不可选择的装饰，标题仍为原生文本。
- 二级标题：加粗，保留标题与正文之间的一行留白。
- 三级标题：加粗、轻微缩进、正文紧接；窄屏缩进减为一列。
- 四至六级标题：采用普通字重、轻微缩进和紧凑间距，避免所有标题都像主标题。
- 引用：侧边线和深灰表面，文字保持正文对比度；明暗主题跟随现有配色。
- 发言人：强调用户名字与助手回答标题，消息序号使用普通字重及辅助灰阶。
- 成功工具记录：缩进一列、收成一行摘要，移除收起状态下额外段间空行。完整参数与结果仍可展开；失败标题加粗，错误正文保持正文对比度，详情默认展开。
- 用户原文、代码字符、历史数据和输入内容不改写。Markdown 空白 token 不再叠加多余空行；正常段落保留一行间隔。
