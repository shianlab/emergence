# 文字层级第一阶段：终端复测与 A/B 样张

2026-11-16。仅新增独立探针和产物，正式 TUI 未修改，未连接任何模型。

## 复测结论

实际 Windows Terminal 返回 scaled_text=false、sixel=true；120 列 × 30 行对应 1200 × 600 像素。此环境不能通过现有原生文字接口给辅助行单独设置小字号。Sixel 可以显示小字号图形文字，加载成功，但它不具备普通文字的选择复制语义，也不能自动作为原生文本供屏幕阅读器读取。小字仍占一个字符行，并不节省行高。

## 两版样张

- A：标准原生字号，以加粗标题、段落留白和紧凑辅助行分层，全部内容保留原生文本。
- B：模型说明、普通回执、共享项目和目录/Tokens 用小字号图片；正文、输入和重要确认保持原生文本。字号试验目标为 87.5%；具体像素值基于字符行高 × 0.8 × 0.875 估算，不是对终端字体实际字面高度的精确测量。使用 Cascadia Mono 与系统中文字体回退。

入口：`emergence/probes/typography-preview.cmd`。F1/F2 切换，F3 显示重要提示，F4 模拟原生文本回退，Esc 退出。所有状态和 Tokens 均为标明的示例数据。输入区可以试打字，不提交任务。

## 已验证

类型检查通过。实际终端内置探针验证 8 项通过：A 辅助文字存在、B 用图像替换辅助行、正文保持原生、重要确认保持原生、回退恢复文字、切换保留草稿、底部操作提示可见、全部图像加载成功。证据在 `artifacts/tui-typography-phase1/checks.json`、`native-report.json` 与 `native-frames.json`。

检查工具未枚举到 Terminal 窗口，因此未取得原生窗口截图，不把回执或字符帧当作截图比对结论。中文小字舒适度、不同缩放后的清晰度与快速重绘残影，需在已提供的原生样张中人工验收。窗口改变大小时会重新按像素尺寸生成辅助行；这一自适应分支尚未完成真实窗口缩放验收。

## 进入下一阶段前

用户比较 A/B 后确定方向。B 应作为有图形能力终端的可选模式；需要文本复制或屏幕阅读的场景使用 A。若小字清晰度或兼容性不合格，不把图形文字推广到正式界面。无需更换首页或扩大 Agent 编排范围。
