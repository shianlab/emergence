## 实际能力

新增原生 `emergence_data_methods`、`emergence_data_analyze`、`emergence_data_definition`，与第四阶段的画像和只读 SQL 共用输入、权限、进程预算。方法目录按需返回，不安装外部 Skill，不复制 31 份全文到每轮上下文。

| 方法 | 已实现 | 明确边界 |
|---|---|---|
| 清理 | 显式 trim、整行去重、缺失保留、IQR 异常标记、行数守恒 | 不自动删除异常值或填零；类型画像沿用第四阶段 |
| 指标 | 分组/等值过滤、唯一键检查、求和、比率、加权均值；Decimal 与 DuckDB 双路复算 | 比率使用总分子/总分母；缺失数值拒绝；SQL 数值精度范围不足时明确报错 |
| 对账 | 按实际键频率计算关联后行数、识别多对多和两侧金额差 | 输入是单张带 left/right 来源的规范表；未新增多文件连接器 |
| 留存 | 完整注册人口作分母、用户去重、按注册日和周期计算 | 需提供未活跃用户；未成熟观察期返回空，不记作零 |
| 漏斗 | 事件排序去重、严格先后、首次入口、完成时限、未结束观察窗口 | 相同时间戳不视为有先后；需要显式时区 |
| 贡献 | 前后期分组贡献与总体变化对账 | 仅可加总指标；不是因果归因，也不直接相加转化率 |
| A/B | 随机化单位唯一性、二元 Fisher 检验、精确区间、效应差、SRM、Bonferroni | 仅独立两组 0/1 结果；不宣称支持连续指标、聚类或序贯实验；随机分配须有业务依据 |
| 序列 | 日粒度缺期标记、训练期趋势/MAD 异常、固定季节朴素基线、时间留出 MAE/WAPE | 缺期不擅自填补；不以留出集选周期；不是通用预测模型 |

数值计算补了大数差分反例：默认 Decimal 的 28 位精度会吞掉大额合计中的微小变化，当前按受限输入范围使用 512 位计算精度；超出数值大小、位数或尺度预算明确拒绝。统计算法调用成熟实现：[SciPy Fisher 精确检验](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.fisher_exact.html)、[二项精确检验与区间](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.binomtest.html)。未将参考脚本中的演示数据、错误零值处理或伪置信区间直接内置。

## 口径、证据与 KIM

项目口径保存名称、方法与参数、公式、粒度、分子分母、过滤、时区、单位、来源、假设和版本。长期保存必须通过宿主确认；未保存确认的本次口径标记 `assumed`，模型不能伪造 `user-confirmed`。同名更新做版本比较，跨项目隔离；引用已确认口径时方法和参数必须一致。

固定分析只读取项目数据，报告写入宿主配置目录 `core/data-runs/<UUID>/`，计划模式可运行；保存确认口径与任意 Python/Shell 不因此放开。原生退出码、输入/口径版本和输出文件哈希接入现有回执。独立 verifier 可实际重算，reviewer 可独立读取审查；复用已有任务、权限和验收，不建立第二套调度器。变更输入、已确认口径或任一交付文件后，旧验收版本失效。

实网调试发现方法目录被待澄清状态错误阻挡，已将纯目录查询纳入规划安全查询；实际计算仍遵守待澄清限制。指导模型先检查已给文件，再判断关键未知，不能把可从数据读取的列或时期标签误当用户决策。

源文件不变；HTML 转义、无脚本 CSP、CSV 公式文本防护已覆盖。CSV 防护不篡改 JSON 原值。图表最多展示 40 行，HTML 表格最多 1000 行，完整结果保留在 CSV/JSON。内置输入限制延续第四阶段：8 MiB、1万行、128列、10万单元格，30秒固定计算及有界输出；Python venv 是依赖隔离，不能称为任意代码安全沙箱。
