# 涌现界面与交互方案

## 默认布局

```text
涌现 · Emergence     工作空间：开发     独立 / 协作
┌ 会话 A · 项目 A · 模型 X ┬ 会话 B · 项目 B · 模型 Y ┐
│ 消息、流式输出与工具卡    │ 消息、流式输出与工具卡    │
│ 独立滚动                 │ 独立滚动                 │
│ > 草稿                   │ > 草稿                   │
└─────────────────────────┴─────────────────────────┘
焦点：A    运行 1 · 待确认 1    切换 / 分屏 / 最大化
```

正式界面顶部显示模式与工作空间，窗格标题显示实际项目、模型及运行状态，底部展示焦点对应操作。任务列表按需展开。焦点边框使用色彩与标记共同表达，不能只依赖颜色。

## 窄屏

终端放不下两个窗格时，仅显示焦点窗格，同时保留其他会话的状态与切换入口。恢复宽度后恢复布局，不销毁会话、编辑器或滚动状态。阈值根据最小可用窗格尺寸计算；原型使用 72 列，正式布局阶段调整。

## 协作布局

主控窗格有明确角色标记，执行窗格显示任务来源及排队项。可用“一主控两执行者”布局，任务列表可代替辅助面板。模式切换保留全部会话，用户选择参与者；切回独立模式停止新派发，已派发工作继续并保持可追踪。

## 操作规则

| 操作 | 行为 |
| --- | --- |
| Tab（原型） | 切换窗格焦点；正式编辑器补全与全局键位在第二阶段统一 |
| 多行粘贴 | 插入草稿，不触发发送，保留完整 Unicode |
| 后台任务等待确认 | 显示带会话归属的通知，不抢走焦点 |
| 隐藏窗格 | 保留会话运行，可从会话列表重新打开 |
| 停止当前任务 | 只取消指定会话，等执行停稳后更新状态 |
| 退出应用 | 清理会话、订阅和终端模式，未完成工作明确提示 |
| 切换模型 | 对下一轮生效，显示确切路由，不静默丢弃历史 |

## 当前原型边界

`npm run demo` 可以验证双窗格输入、滚动和缩放；`--four` 为四个纵向区域。F2 切换“独立/协作草图”文字，尚未执行主控调度。界面运行受控输出，不会调用外部模型。左右/上下任意分割、拖拽调宽、任务列表和正式工具卡仍按阶段二/三实现。
