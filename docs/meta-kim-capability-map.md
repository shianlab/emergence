## 两套流程

上游八阶段主循环为 Critical → Fetch → Thinking → Execution → Review → Meta-Review → Verification → Evolution。中文分别为意图确认、证据与能力发现、方案规划、执行、审查、审查标准复核、验证、经验沉淀。

十一阶段业务流程：方向、计划、执行、审查、元审查、修订、验证、总结、反馈、进化、组织复盘。

两者关系由 Emergence 显式记录为多对多关联：方向关联 Critical/Fetch，计划关联 Thinking，修订回到 Thinking/Execution，总结关联 Verification，反馈关联 Critical/Evolution，进化与组织复盘关联 Evolution；其余同类阶段对应。该关联是本项目的整合解释，不伪称上游提供了同一张可直接执行的图。
