# Emergence 1.03 · 安装更新与并发稳定性

2026-11-17 · 程序版本 `1.0.3` · Windows x64。

本版包含 1.02 的安装更新体系，并修复发布收尾时重复验收发现的两个偶发并发问题。1.02 已公开的文件保持原样，不复用同一版本号替换程序；新安装请使用 1.03。

## 功能与修正

- 下载限时重试、可验证续传、缓存复用和分阶段进度；安装前检查完整性及实际启动。
- 安装、升级、修复、回退共用事务。运行中的旧窗口受到保护，保留可回退版本，配置、加密密钥、会话和项目不参与程序清理。
- 后台检查签名稳定版，默认缓存 6 小时；中文 `/update` 菜单和 `emergence update --check` 提供手动检查。发现新版后由用户选择更新，网络失败不阻塞任务。
- Windows 8.3 短路径不再被误判为目录跳转；仍拒绝越界、目录链接和无所有权的清理。
- Windows 原子文件替换期间，读取对瞬时文件不可见/占用做有限重试，每次重新校验文件类型与大小；真正缺失、内容损坏和超过上限仍报错，不返回伪造的空数据。
- 拒绝审批或取消任务后，下一模型步立即检查取消状态，不再等待异步持久化完成才停止。独立窗口、单会话子代理和权限边界保持不变，不恢复跨窗口协作。

## 安装与迁移

```powershell
irm https://raw.githubusercontent.com/shianlab/emergence/main/install.ps1 | iex
```

1.00/1.01 用户需执行一次上述安装，才能获得此前没有的更新检测功能。已安装 1.02 的用户可执行 `emergence update` 或使用 `/update`。自定义安装目录请使用[安装指南](../installation.md)的显式参数，保留原 `-NoPath` 选择，不要先删除旧安装或配置。

安装完成后新开终端，`emergence --version` 应为 `1.0.3`；旧窗口继续运行旧版。

## 验证与边界

1.02 候选已完成本机完整矩阵，用户确认外部电脑安装、模型配置及真实任务正常。该反馈不冒充本次并发修正后的外部电脑验收。后续检查、包指纹及公开入口验证统一记录在[1.03 发行核验](../release-audit-1.0.3-2026-11-17.md)。

仅 Windows x64；原生模型配置需要 .NET Framework 4.8，数据分析另需 CPython 3.14 x64。需用户自己的模型凭据。仍依赖 GitHub 网络可达，不承诺固定下载速度。清单有发布者签名，原生 EXE 尚无商业 Authenticode 签名；两者不可混同。
