# Emergence 1.00

首个公开 Windows x64 版本。程序语义版本 `1.0.0`，Git 标签 `v1.0.0`。

## 安装

```powershell
irm https://raw.githubusercontent.com/shianlab/emergence/main/install.ps1 | iex
```

发行包：`Emergence-1.0.0-win32-x64.zip`，附 `.sha256`。内含 Node 26.13.0、锁定生产依赖、CLI、原生模型配置工具、安装/卸载脚本、组件清单及完整许可。手动下载请选择发行 ZIP，GitHub 的 Source code ZIP 不包含运行依赖。

安装、更新、回退与卸载见[安装指南](../installation.md)。

## 本版范围

中文 TUI、模型选择、独立多窗口、KIM、代码和数据工具、Skills、MCP、规则文件、历史与权限审批。不提供主控窗口和跨窗口派活。

模型密钥及 API 费用由用户自行提供。数据计算另外需要 CPython 3.14 x64，并显式运行 `emergence data-init`。

## 已知限制

- 仅 Windows x64；推荐 Windows 11 + Windows Terminal，需 .NET Framework 4.8。
- 原生组件和脚本未做商业代码签名；摘要及逐文件校验用于完整性检查。
- 第三方网关需匹配所选协议，本地协议测试不能保证所有在线服务兼容。
- Shell/MCP/Skill 在当前用户权限下运行；应用审批不是操作系统沙箱。
- 输入法、字体及图形协议由终端决定；无图形支持时品牌按文字降级。
- 并行编辑同一项目需用户协调，建议使用独立 Git worktree。

本机巡检记录见[巡检报告](../release-audit-2026-11-16.md)。最新 CI 结果以仓库 Actions 为准。反馈请附版本、环境与最小复现，不附密钥或敏感数据。
