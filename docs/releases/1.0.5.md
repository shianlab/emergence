# Emergence 1.05 · 终端排版与输出恢复

2026-11-19 · 程序版本 `1.0.5` · Windows x64。

## 对话界面

- 输入框采用完整细灰边框，保留原有可编辑行数。会话标题上移，输入区与目录、Tokens 底栏留出间距。
- 模型说明、普通回执、收起的共享项目摘要、目录和 Tokens 使用小字号。正文、输入、审批、错误和展开详情继续使用可选中的原生文字。
- 模型集中在窗格顶部，目录集中在底栏。分屏、缩放和终端底部绘制增加边界保护，避免重影、滚屏和底栏遮挡。
- 小字号依赖终端图形协议，图形文字无法选中复制。图形不可用时自动回到原生文字。需要始终使用可复制文本时，启动前设置 `EMERGENCE_NATIVE_TEXT=1`。

## 任务恢复

- 当模型达到单次输出上限且本步工具尚未提交，涌现保留已经完成的操作，缩短当前步骤并在同一轮重试一次。
- PDF 和长文档先分段写入源稿，再单独转换并检查产物。各模型的输出预算可在 `/model-config` 单独设置。

## 更新

在工作台输入 `/update`，或在 PowerShell 运行 `emergence update`。更新后，新启动的窗口使用新版本。完整安装和回退说明见 [安装指南](../installation.md)。
