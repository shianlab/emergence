# Emergence 1.02 · 安装与更新

2026-11-17 · 程序版本 `1.0.2` · Git 标签 `v1.0.2` · Windows x64。

本次更新完善从首次安装到后续升级的完整路径，保留中文 TUI、独立多窗口、KIM、Code/Data、Skills、MCP、记忆、审批和原生模型配置。不恢复主窗口或跨窗口派活。

## 主要变化

- 下载增加限时重试、可验证的断点续传、下载缓存和分阶段进度。失败后重试可复用已验证内容。
- 新版本先部署并实际验证启动，再切换入口。安装、更新、修复、回退共用事务，失败或中断有恢复记录。
- 更新写入独立版本目录，正在运行的旧窗口继续工作。保留上一份可用版本；占用中或无法可靠识别的文件不强制清理。
- 兼容 Windows 临时目录的 8.3 短路径，避免失败恢复和旧版清理被合法路径别名阻断。
- 启动后台检查官方稳定版，缓存默认 6 小时。中文 `/update` 菜单支持查看说明、确认更新、稍后以及关闭自动检查；网络故障不阻塞正常任务。
- 更新清单采用发布者签名，客户端与独立安装器均验证签名、版本、平台、字节数和 SHA-256。拒绝坏包和伪造清单。
- `doctor` 增加安装来源与更新状态；安装诊断记录失败阶段和耗时，不记录模型密钥。

## 从 1.00 / 1.01 迁移

旧版本不包含检测更新代码，需要手动迁移一次。下载本版本的 **Windows x64 完整 ZIP**（不是 Source code），解压后在发行目录执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1
```

若旧版安装在自定义位置，添加 `-InstallRoot "D:\Apps\Emergence"`，使用原来的安装目录。原有 `-NoPath` 用户迁移时继续指定 `-NoPath`。安装后启动新窗口，执行 `emergence --version` 应显示 `1.0.2`。配置、加密密钥、会话、项目和数据环境保留；不需要先卸载旧版。

新用户及旧用户可统一执行：

```powershell
irm https://raw.githubusercontent.com/shianlab/emergence/main/install.ps1 | iex
```

指定目录或离线安装见[安装指南](../installation.md)。正在运行的窗口继续使用旧版本，新启动的窗口使用新版本。

## 后续更新与维护

```powershell
emergence update --check
emergence update
emergence installation status
emergence rollback
```

TUI 中使用 `/update`。发现新版不会直接安装，需要用户选择；安装完成后新启动生效。便携版和源码运行不自动覆盖目录。

同版本文件损坏时，下载并解压完整同版发行包，然后执行：

```powershell
emergence repair --source "D:\Downloads\Emergence-1.0.2-win32-x64"
```

如果命令入口本身无法启动，直接重跑完整包的 `install.ps1`。回退只回退应用，不回滚用户数据；没有兼容且健康的上一版本时明确拒绝。

## 限制与验收

安装仍需访问 GitHub 官方下载服务。重试和缓存不能保证被网络阻断的地址可用，也不承诺固定下载时间或包体大幅缩小。原生 EXE 尚无商业代码签名；更新清单签名与 Windows Authenticode 是不同机制。

仅 Windows x64；原生模型配置需要 .NET Framework 4.8，数据分析另需 CPython 3.14 x64。用户自行配置模型服务。应用审批不是操作系统沙箱。

本机通过 45 项完整检查、379 项单元/集成测试、40 项安装专项，以及 PowerShell 5.1/7、1.00/1.01 实包迁移、维护和在线更新验收。用户随后确认外部电脑安装、模型配置及实际任务正常；这项结论来自用户反馈，没有额外机器日志。候选验收记录见[第四阶段报告](../installation-phase4-report-2026-11-17.md)，正式发行核验见[发布记录](../release-audit-1.0.2-2026-11-17.md)。
