# Emergence 1.0.1-rc.1 候选说明

这是七阶段结构整理后的本地候选版本，尚未发布到 GitHub，也不改变公开安装命令当前下载的 1.00。原生配置窗口仍等待用户手动验收。

## 保留的产品能力

独立多窗口、各窗口的项目和模型、中文 TUI、审批、历史恢复、KIM 内置分析与规划、单会话任务、Code/Data、Skills、MCP 和记忆继续保留。主窗口和跨窗口控制继续退出，不会因读取旧历史而恢复。

## 主要变化

- 会话生命周期、权限、交互与展示各有明确责任方；规划状态由一个入口管理，迟到结果不能覆盖新请求。
- 单会话执行引擎接替退役协调器的共享职责，任务事实仍由执行台账保存，未知副作用不会自动重放。
- Code/Data 通过能力接口接入；TUI 输入、窗口视图及提示分工，原生配置工具分离编辑草稿和连接生命周期。
- 自有 TypeScript、C#、Python、PowerShell 统一进入固定版本的规范检查；第三方与生成资产保留独立校验范围。
- 修正频繁界面刷新时重复读取脱敏信息造成的输入延迟，保留实时密钥轮换和终端控制字符过滤。

## 安装与数据

候选 ZIP 随附 Node 运行时、原生模型配置和校验清单。解压后可以直接运行 `emergence.cmd`；需要安装时，使用包内 `install.ps1`。试用候选建议使用独立安装目录及 `--home` 配置目录。

升级通过新包的安装脚本切换应用版本；回退重新安装原 1.00 包。配置、加密凭据、历史和项目数据不随卸载删除。不要手工替换单个运行文件或复制其他机器的 DPAPI 凭据。

## 验证范围与剩余事项

完整证据及发现的修正见 [第七阶段报告](../structure/phase7-report.md)。在线检查只覆盖本机已配置的 DeepSeek/智谱线路；未配置的外部 MCP 不能算作已验证。五分钟稳定性结果不代表全天运行。实际 Windows Forms 点击、输入法候选窗口与字体呈现仍需要用户操作确认；未执行 GitHub 在线 CI 或公网候选下载。
