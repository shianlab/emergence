# Emergence 1.01

2026-11-17 · 程序版本 `1.0.1` · Git 标签 `v1.0.1` · Windows x64

本次更新集中整理核心结构、改善输入性能和完善安装兼容。独立多窗口、KIM 内置分析与规划、单会话任务、Code/Data、Skills/MCP、记忆、审批和原生模型配置继续保留。

## 更新内容

- **会话与规划更清晰**：生命周期、授权、展示和规划状态由明确模块管理，防止会话切换后的迟到结果更新错误请求。
- **移除退役协同实现**：保留本会话执行引擎和旧历史读取；不再构造主控协调器，也不会通过恢复旧记录重新启动跨窗口控制。
- **界面职责整理**：输入路由、窗口视图、提示与资源释放分工；原生模型配置分离编辑草稿和连接生命周期，避免关闭后的响应更新旧控件。
- **输入响应优化**：一次同步刷新共用脱敏快照，减少 Windows 环境变量重复读取；独立诊断和下一次刷新仍读取最新凭据。
- **维护规范统一**：TypeScript、C#、Python、PowerShell 使用固定版本检查工具；第三方和生成文件按明确范围验证。

## 安装与更新

在 Windows PowerShell 中执行：

```powershell
irm https://raw.githubusercontent.com/shianlab/emergence/main/install.ps1 | iex
```

已有安装使用同一命令更新，重开终端后执行 `emergence --version`，应显示 `1.0.1`。自定义目录可下载脚本并传入 `-Version 1.0.1 -InstallRoot "你的安装目录"`。首次使用通过 `/model-config` 配置模型。

手动下载请选择 `Emergence-1.0.1-win32-x64.zip` 和同名 `.sha256` 文件；GitHub 自动提供的 Source code ZIP 不包含运行依赖。包内自带 Node 26.13.0、生产依赖、原生配置工具、安装/卸载脚本及许可证，无需预装 Node/npm。

配置、DPAPI 密钥、历史和项目数据与应用分离，升级和卸载保留这些数据。需要回退时，关闭运行实例后用 1.00 包的安装脚本安装到同一目录。完整步骤见[安装指南](../installation.md)。

## 验证与限制

七阶段候选已完成 44 项完整检查、331 个单元与集成测试、五分钟稳定性、真实模型读写、三种终端以及安装/升级/回退验证。用户已确认原生窗口可以正常使用。正式版本发布前再次执行固定源码回归和安全检查；CI 以[仓库 Actions](https://github.com/shianlab/emergence/actions/workflows/ci.yml)的对应提交结果为准。

输入性能修正的同机五分钟复测 P95 为约 101 ms，修正前约 176 ms；该数据不代表每次输入或公网模型延迟。仅本机已配置的 DeepSeek/智谱进行了真实线路验证；其他供应商和外部 MCP 需按各自配置验证。

仅发布 Windows x64。原生工具需要 .NET Framework 4.8，数据分析需另行准备 CPython 3.14 x64。应用审批不是系统沙箱。主窗口控制和跨窗口派活不在本版本范围内。

完整变更见 [CHANGELOG](../../CHANGELOG.md)，结构依据见[维护指南](../structure/README.md)。反馈问题请附版本、环境及最小复现，不附密钥或私有项目内容。
