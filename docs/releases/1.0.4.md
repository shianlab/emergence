# Emergence 1.04 · 狂暴模式与权限快捷键

2026-11-18 · 程序版本 `1.0.4` · Windows x64。

## 新增

- **狂暴模式**为当前窗口自动批准工具调用，覆盖该窗口的工具 allow、ask、deny 规则。Shell、项目外文件操作和已连接的 MCP 工具可直接执行。操作系统权限、工具校验、任务中的只读和禁止约束继续生效。
- **五档快捷键切换**。工作台中按 `Shift+Tab` 按「计划 → 询问 → 自动编辑 → 自动执行 → 狂暴模式 → 计划」循环。也可使用 `/permission` 菜单或 `/permission rage` 直接开启。
- **按窗口开启**。各分屏独立选择权限。狂暴模式仅在本次打开的窗口生效，重启后使用常规默认权限。自动批准的数据口径会在记录和报告中标明批准方式。
- **发行包依赖**。移除已禁用的 Harness 热重载功能所用的 `picomatch`。上游源码依赖锁仍会报告这项公告，Windows 发行包不含该模块。[依赖公告](https://github.com/advisories/GHSA-fc5q-39xc-vjpf)

## 升级

1.02 及更新版本可在工作台输入 `/update` 检查更新，或在 PowerShell 运行 `emergence update`。1.00 和 1.01 需要用当前 [安装命令](../installation.md) 迁移一次。

安装后重新打开涌现，`emergence --version` 应显示 `1.0.4`。进入工作台后即可使用新快捷键。如果还在首页，可先输入 `/new` 或 `/continue`。查看完整变更记录请访问 [CHANGELOG.md](../../CHANGELOG.md)。
