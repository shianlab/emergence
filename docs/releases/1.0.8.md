# Emergence 1.08 · Windows 更新兼容性

2026-11-20 · 程序版本 `1.0.8` · Windows x64

- GitHub Raw 连接失败时，涌现使用同一 GitHub 仓库的公开 API 读取稳定版清单。发布者签名、有效期、发行序号和发行包哈希继续校验。
- 从 PowerShell 7 启动离线更新、修复、回退或安装维护时，Windows PowerShell 使用自身的模块搜索路径。
- 包含 [1.07](1.0.7.md) 的凭据隔离、任务收尾、更新恢复、终端空闲优化和数据分析校验。

旧版可以在获取清单成功时使用 `emergence update`。如果旧版无法联网检查，按 [安装指南](../installation.md) 下载并校验完整发行包，再使用随包的 `install.ps1` 更新现有安装。更新保留用户配置、密钥和历史会话。
