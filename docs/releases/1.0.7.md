# Emergence 1.07 · 凭据隔离与运行稳定性

2026-11-20 · 程序版本 `1.0.7` · Windows x64

## 安全与任务执行

- 模型密钥留在应用的凭据读取路径中。Shell、MCP 及普通工具子进程按各自配置获得环境变量。终端与诊断统一遮盖凭据，Windows 文件路径使用统一校验。
- 任务台账持久保存排序和删除。即使取消时首次保存失败，任务也继续收尾并释放只读工具限制。重启后的任务顺序沿用已保存记录。
- 在线更新直接显示安装失败原因。安装超时后，现有安装管理器负责恢复事务，可重新检查和安装。

## 终端与数据

- 工作台空闲时停止刷新定时器和无变化重绘。思考动画、运行时间和临时回执仍在需要时更新。
- 编程提示按独立会话中的探索、实现和验证组织。旧模板可恢复独立窗口。Markdown 显示支持标准的 `AMP`、`LT`、`GT` 和 `QUOT` 字符别名。
- 验证数据分析结果的格式和本次请求。Excel 读取前检查文件部件、解包预算和归档完整性。
- Windows x64 发行包仅保留该架构的终端预编译文件，省去调试符号。

## 安装与更新

在涌现输入 `/update`，或在 PowerShell 运行 `emergence update`。更新完成后，新开的窗口使用 1.0.7。安装事务保留可用的上一版供回退，配置、密钥和历史会话存放在独立的用户目录。[安装与回退说明](../installation.md)
