## 开始使用

退出旧进程后，重新运行 `emergence`。当前本地构建已更新。

| 命令 | 用途 |
|---|---|
| `/instructions` | 查看规则来源、作用域、优先级、摘要、字节数、指纹和加载问题 |
| `/instructions reload` | 重新读取规则；忙碌时在下一模型请求前生效 |
| `/instructions path "src/模块"` | 查看并把指定项目内目录的规则纳入下一模型请求 |
| `/instructions config` | 查看当前规则配置 |
| `/init` | 预览项目规则草案 |
| `/init personal` | 预览个人长期偏好草案 |
| `/init local` | 预览项目本地覆盖草案 |
| `/init apply` | 按当前窗口权限写入已预览的草案 |

初始化会识别项目类型，以及 package.json 中已存在的构建、检查与测试脚本名称，生成可编辑模板；不会执行这些命令。它不是完整的模型仓库分析。已有规则保留原文，只追加尚不存在的初始化段；写入前核对预览版本，发生外部修改则拒绝覆盖，修改旧文件时保留原文备份。确认弹层可以用方向键和 Enter 操作。

计划模式阻止初始化写入，询问模式要求确认，自动编辑模式遵循项目边界；项目外的个人规则仍需确认。预览不会自动写文件。`.local.md` 不会自动加入 Git 忽略，需要用户按项目约定处理。

## 文件与作用域

```text
~/.emergence/EMERGENCE.md       个人长期偏好
项目/EMERGENCE.md               项目共享约定
项目/EMERGENCE.local.md         本机项目覆盖
项目/src/EMERGENCE.md           src 范围的规则
项目/src/EMERGENCE.local.md     src 范围的本地覆盖
```

个人目录跟随 `--home` / `EMERGENCE_HOME`，默认是 `~/.emergence`。支持小写 `emergence.md` 和 `emergence.local.md`；两种拼写同时存在时优先规范名，并按物理文件去重。实际 Windows 行为已验证，其他操作系统未做本轮终端验收。

默认以最近的 Git 根为边界，支持普通 `.git` 目录及 worktree 的 `.git` 文件；无 Git 时以该会话的启动项目目录为边界。`rootMode: "launch"` 可固定为启动目录。不会把项目外父目录的规则一路加载进来。

先加载个人规则，再加载项目根到实际操作子目录的规则。更具体目录的规则只适用于该目录；同一作用域的优先级为 `EMERGENCE.local.md` > `EMERGENCE.md` > `AGENTS.md` > `CLAUDE.md`。直接用户指令和运行时权限始终优先。这里提供来源与顺序，不声称能自动识别任意自然语言规则之间的语义冲突。

`AGENTS.md` 默认兼容，`CLAUDE.md` 默认关闭。已关闭 Harness 的旧指令加载插件，避免旧全局目录和 Emergence 重复注入。供应商、运行时与开源归属不作改名冒充。工程自身的约定已写入 `emergence/EMERGENCE.md`。

不同窗口按各自项目加载规则；原生子代理按实际会话目录计算边界。每次模型请求前重新读取已纳入范围的文件，未变化的快照不重复注入。恢复会话后也会读取当前内容。删除文件会生成新的有效快照，历史中的旧快照仍保留，并明确由新快照取代。这不是后台文件监控，也不能撤回已经发出的模型请求。

## 子目录与权限保护

原生 read/read_image/glob/grep/write/edit 的目标路径会纳入目录规则检查。先读后改时，子目录规则在下一次模型请求前进入上下文；若模型直接写入尚未了解规则的子目录，本次写入先被阻止，下一请求载入规则后可重新提交。等待人工确认期间规则变化，也会在实际写入前重验。

文件大小、总上下文预算、UTF-8 格式、目录边界或读取错误会显示在来源列表中；相关规则未完整加载时阻止原生写入。不会把规则切成半段后假装完整加载。符号链接或 junction 不能把项目外文件当成项目规则读入。

任意 Shell、MCP 或扩展内部访问了哪些文件，无法仅靠参数普遍解析。需要这些工具操作特定子目录时，可先 `/instructions path "目录"` 或读取目录内文件以载入规则。这里不承诺完整文件系统沙箱；外部程序仍可能并发改文件。规则文档不能授予命令权限、开启扩展或直接改变配置，实际工具执行继续经过 E2 权限引擎。

## 配置

在 `config.json` 中设置，其他配置字段保留：

```json
{
  "instructions": {
    "rootMode": "git",
    "agents": true,
    "claude": false,
    "maxFileBytes": 65536,
    "maxTotalBytes": 32768
  }
}
```

上述为默认值。每个会话最多纳入 64 个目录；总预算包含规则上下文的结构开销。旧配置自动取得内存默认值；需要持久迁移时沿用已有配置迁移与备份机制。空闲时 `/settings reload` 应用配置；`/instructions reload` 用于规则正文更新。切换配置不自动放宽执行模式。

长期偏好由用户在这些文件中明确保存、编辑或删除；本阶段没有自动记忆抽取或独立的记忆管理器。角色档案和更完整的编排属于 E4。
