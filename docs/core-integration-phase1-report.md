# 核心整合第一阶段交付与巡检

日期：2026-10-30。对应 `docs/emergence-core-integration-plan.md` 第一阶段。

## 已完成

- 首页与对话页输入 `/` 自动显示可用命令，支持中文用途搜索，例如 `/模型`。共用命令定义驱动列表和帮助，优先显示帮助、模型和权限等常用操作。
- ↑↓ 选择、Tab 补全、Enter 确认、Esc 收起。带必填参数的操作先回填输入框，并提示补充参数；菜单方向键选择不会被原输入的精确匹配项覆盖。
- 首页未知斜杠命令不再作为普通任务提交给模型；路径、多行草稿和参数输入不被菜单替换。无匹配项会显示中文提示。
- `/help` 按用途分组，包含说明、实际快捷键和例子；支持 `/帮助`、单独输入 `help` 或“帮助”。正常句子中的“帮助”不会被拦截；审批中的自由回答仍保留回答语义。
- 首页帮助可以用 ↑↓、PgUp/PgDn 翻页，Esc 返回并保留草稿。工作台帮助沿用已有滚动与返回行为。
- 每个窗口输入框上方显示真实状态：等待模型响应、收到推理流时的思考、输出、工具调用、等待回答/审批、排队、停止、失败和就绪。
- 运行状态显示本轮经过时间，等待较久时提供当前实际停止快捷键。未收到推理事件时不显示“正在思考”，不提供虚构进度百分比。
- 运行提示采用柔和琥珀色，其余既有黑白灰视觉保留。支持灰阶和减少动效，兼容 NO_COLOR、TERM=dumb 与已有减少动效环境变量。
- 已更新本机 `dist` 构建。运行中的旧进程需要退出重开才能加载代码。

## 使用方法

1. 重启 `emergence`，在首页输入 `/`，或继续输入 `/模型` 搜索。
2. 用 ↑↓ 和 Enter 选择，Tab 只补全，Esc 收起列表。
3. 输入 `/help` 或“帮助”查看中文说明。
4. 提交任务后，观察输入框上方的状态、经过时间和排队数量。
5. 对话页中运行 `/activity` 查看状态设置：
   - `/activity color gray`：灰阶状态。
   - `/activity color amber`：柔和琥珀色。
   - `/activity motion reduced`：减少动效。
   - `/activity motion normal`：恢复动效。

设置写入当前 Emergence 配置；不修改其他 Agent 配置或凭据。
