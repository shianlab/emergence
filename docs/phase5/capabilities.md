# 第五阶段能力对照

对照 `docs/phase1/capabilities.md` 的历史基线；不改写阶段一当时的验证结论。执行底座仍为 DeepSeek Harness 0.2.2-alpha.2，应用版本 0.0.5-phase5。

| 阶段一能力 | 当前交付 | 验证入口/限制 |
| --- | --- | --- |
| 创建/释放 | 独立窗口和原生子代理；会话、工作台跨进程互斥 | 原有 Harness/关闭窗口/安全测试；16 窗口短时并发后 Registry 为空 |
| 流式输出、取消、排队 | 按会话归属渲染；窗口和协作任务独立取消 | 前四阶段终端回归；后台状态不抢焦点 |
| 模型路由 | 多配置、协议、预算和能力声明；当前窗口切换 | 四种协议配置入口；OpenAI/Anthropic 本机协议、DeepSeek 实网有既有证据；另一真实供应商待验 |
| 历史兼容 | 保留原日志，检查明确声明的工具/图像限制；忙碌时禁止切换 | 不兼容切换拒绝且事件数不变；不会静默新建/裁剪历史 |
| 工具执行 | 正式 profile 的原生文件、Shell、Skill、网络、任务等工具；扩展工具复用执行链 | `/tools` 显示真实定义；各工具的外部服务需求仍需实际配置 |
| 目录隔离 | 每窗口独立项目、独立模型、独立草稿；模板保存完整绑定 | 中文/空格目录、多项目、多模型、共享项目回归；MCP 为工作台共享服务 |
| 历史/恢复 | JSONL 会话、布局恢复、模板创建新会话并备份旧布局 | 重启不自动重放任务；模板失败保留原窗口；档案不含密钥和会话 ID |
| 审批、问卷 | 按实际运行时所属窗口路由；deny/confirm 规则；最终执行 guard 再检查 | 配置的 write 确认、Shell 允许/拒绝、子代理所有权及伪造 lineage 拦截 |
| Skill | 当前作用域发现、查看、显式调用与原生 skill 工具 | 真实项目 SKILL.md；显式调用使用 Harness 的 renderSkillContent 和 skill-invocation，保留资源基路径 |
| MCP | stdio 服务，启停、失败隔离、名称/工具释放和重新连接 | 真实本机 MCP 服务；坏服务不影响好服务；工具调用走正式 profile |
| 子代理 | 原生 subagent 调用，活动代理和持久目录查看，历史只读查看，活动代理停止 | 原生子代理写入文件；委派策略 never 自动拒绝需审批的命令；不擅自放宽权限 |
| 设置与凭据 | 兼容旧配置、原子更新；主题/快捷键/状态栏/界面语言；DPAPI 凭据 | 冲突配置拒绝保存，主题更新不带入其他实例的权限修改；扫描已配置凭据的明文匹配 |
| 上下文 | 查看模型预算、实际最后回执、待处理上下文；非唤醒补充；脱敏导出 | 预算是配置声明，回执才是实际用量；首版不另做手动压缩或清空历史 |
| 本地扩展 | 显式 ESM 加载，命令/面板/工具命名空间，失败回滚和资源清理 | 内置 inspector 与磁盘上的 project-notes 示例；中止在途命令、晚到的 activate 清理 |

新增 MCP 的启动参数、自定义 Skill 目录、模型路由或扩展代码变更需要重启。现有 MCP 和扩展可通过界面启停。设置由涌现 `config.json` 保存；会话行为和工具事件继续由 Harness 持久化。

MCP 服务进程属于整个工作台；服务 cwd 不随焦点窗口切换。需要独立服务目录时，配置不同 serverName 和 cwd。HTTP MCP、自定义服务认证界面、额外 Agent 后端和不受信任插件沙箱不在本阶段首版范围内。
