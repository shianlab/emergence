# E5：完整工作流与交互打磨

完成日期：2026-10-30。本机版本已构建。复用现有黑白灰命令列表与消息界面，保留首页、Logo 和首次提交进入会话的流程。

## 操作方式

| 入口 | 行为 |
|---|---|
| `/`、Ctrl+P | 搜索命令；补齐 E4 角色派发、验收、修复和任务导航入口 |
| Tab | 对话输入中存在命令候选时补全，不执行；其余情况沿用窗口切换绑定 |
| Ctrl+R、`/history [关键词]` | 搜索当前会话输入历史；方向键选择，Enter 回填草稿，不发送 |
| `/model` | 搜索模型，方向键与 Enter 选择当前窗口模型 |
| `/roles` | 搜索角色，再选择执行窗口，生成 `/assign-role` 草稿；补充目标和验收标准后自行发送 |
| `/tasks`、F4（默认绑定） | 搜索最近任务；Enter 看详情，右方向键进入实际执行窗口 |
| `/task focus <ID>` | 显示并切换到任务的执行窗口，窗口已关闭时明确报错 |
| Esc、Ctrl+C | 在选择器内关闭并返回，保留原聊天草稿 |
| 选择器内 Ctrl+P | 切回普通命令入口，可执行 `/focus`、`/exit` 等命令 |

多段命令也支持前缀补全，例如输入 `/task a` 后按 Tab 补为 `/task accept `。补全仅补命令名称，不会执行，也不是完整的文件路径、Shell 或参数补全。默认 Tab 的窗口导航保留，自定义快捷键继续由原有配置管理；Ctrl+R 与 Ctrl+P 为固定入口。

历史来自当前会话已有日志，按最近优先去重，最多显示 100 条；包括中文与多行文字。忽略运行上下文、规则注入和协作回执，不复制另一窗口的历史。恢复原会话后可继续搜索，不新增一份明文历史文件。显示和回填使用现有敏感值脱敏函数；这不代表能识别所有未知格式的秘密。历史选择会替换当前草稿，取消选择则保持原稿。

模型选择只作用于当前窗口，运行中或关联协作任务时仍受已有变更限制。角色选择只准备派发草稿，必须在协作主控窗口使用，不静默建立团队或提交新任务。任务导航不自动取消、重派或验收工作；隐藏窗口可以重新显示，关闭的窗口不会被伪造恢复。

## 焦点与确认

选择器绑定打开时的窗口和会话；切换窗口、会话变化或当前窗口出现待确认请求时，旧选择器失效。历史回填和选择提交后的短时 Enter 防重复保护，避免连续回车意外发送草稿。权限确认的 Enter、方向键、Esc、会话许可和取消行为继续由 E1/E2 管理。

后台任务、审批和流式输出不覆盖正在编辑的草稿。没有匹配项时 Enter 不执行；失败的模型切换保留错误和可修改的命令。窄终端减少显示行数，条目保持可滚动选择；历史多行内容在列表中显示为单行摘要，回填保留原换行。

## 建议体验流程

1. 重启 `emergence`，用 `/model` 选择模型，Shift+Tab 或 `/permission` 选择执行模式。
2. 提交一个任务，使用 Ctrl+R 搜索并回填此前输入，检查后再发送。
3. 建立多个项目窗口并配置协作，使用 `/roles` 选择角色及执行窗口，补齐目标和验收标准。
4. 用 F4 搜索任务，查看回执或进入执行窗口；按实际证据验收，需要时创建有限修复。
5. 退出后重新打开，恢复布局和会话，检查历史与任务记录；未完成副作用不会自动重放。
