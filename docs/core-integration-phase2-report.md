## 使用

退出旧进程，重新运行 `emergence`，进入对话后：

| 命令 | 用途 |
| --- | --- |
| `/core` | 核心版本、观察模式与诊断 |
| `/core roles` | 九个内置治理职责 |
| `/core workflow` | 八阶段与十一阶段流程关系 |
| `/core coverage` | 当前已接入范围和外部依赖状态 |
| `/core events` | 当前会话最近观察 |
| `/core instructions` | 指令分层与权限边界 |
| `/core off` | 关闭工作台观察，并保存设置 |
| `/core observe` | 开启工作台观察，并保存设置 |

旧配置未包含 `core` 时默认补为观察模式；手动编辑配置后可在空闲时 `/settings reload`。新窗口继承当前模式。关闭观察不关闭原有 Agent，不改变权限模式或工具授权。
