## XLSX 解包与内存

在同一个 Windows Python 环境顺序运行原版与修订版，使用 OpenPyXL 生成三份四列工作簿。内存取 Windows 进程峰值工作集，时间包含启动、验证和读取。

| 行数 | 解包后大小 | 原版时间 / 峰值 | 修订版时间 / 峰值 | 结果 |
| ---: | ---: | ---: | ---: | --- |
| 250 | 0.16 MiB | 447 ms / 40.6 MiB | 447 ms / 40.8 MiB | 完成 |
| 8,000 | 56.5 MiB | 1,746 ms / 101.9 MiB | 1,931 ms / 101.9 MiB | 完成 |
| 9,200 | 68.5 MiB | 417 ms / 37.6 MiB | 440 ms / 37.8 MiB | 拒绝超预算 |

保留 64 MiB 解包预算，新增 4,096 个文件部件的上限。读取前按块验证 ZIP 内容与完整性，允许 Excel 常用的存储和 Deflate，重复部件返回明确错误。工作簿在选择工作表和异常路径都关闭。当前数据记录描述实测样本，Python 进程仍由既有执行时限管理。
