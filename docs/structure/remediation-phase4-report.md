# 第四阶段候选包验收

候选版本为 1.0.7（Windows x64），来自第三阶段提交 `e0f46dc`。版本号写入隔离构建目录。候选 ZIP 的大小为 225,285,805 字节，完整性清单记录 31,101 个文件，SHA-256 为 `7353bf7e8196b359b550d688b004fa3adef8a3a703f57a9d7ecfe8d7326c87eb`。测试使用该 ZIP 的原样字节和临时签名公钥。

首次封包时发现 npm 包和 CLI 编译版本可以不一致。打包程序现在先核对包版本、锁文件和构建后 CLI 的 `--version` 实际输出。特意保留旧构建执行预检，确认差异在封包前即被拒绝。重建后的便携入口报告 1.0.7，候选通过原生终端依赖、Harness 工具和 Windows Forms 依赖探测。

## 源码与公开入口

- Windows 本机源码检查通过。全量测试 394 项通过，代码规范、架构、构建、独立窗口、GDI 字体绘制、Sixel 布局、状态计时和空闲刷新回归通过。工作台空闲回归已加入 Windows CI。
- npm 审计返回零项已报告漏洞。五个固定版本的 Python 依赖在 PyPI 版本元数据中均无已登记漏洞。源码和候选扫描均比对了两份本机已保存凭据，扫描范围内没有找到相同的明文。
- 线上 1.0.6 稳定清单签名通过校验。实际下载的 225,277,880 字节 ZIP 与清单的 SHA-256 一致。公开引导脚本在 Windows PowerShell 5.1 中从零安装到中文隔离路径，启动报告 1.0.6，随后卸载成功。[1.0.6 发行页](https://github.com/shianlab/emergence/releases/tag/v1.0.6)
- GitHub Actions 的 1.0.6 稳定通道提交通过 Windows 源码检查。1.0.7 候选运行了本机检查和安装矩阵，GitHub 托管运行留到候选提交上传后进行。[公开 CI 记录](https://github.com/shianlab/emergence/actions/runs/44471677561)
- 模型配置服务通过 18 项接口检查，覆盖实际 Harness 路由、历史会话、窗口分配和默认模型。原生窗口依赖由无界面探测验证，桌面操作留作人工验收。

## 安装与迁移

- 发布版 1.0.1 的安装脚本在隔离目录正常运行。版本指针切换时中断，旧启动器能够恢复。完整重试切换到 1.0.7，回退可启动 1.0.1，管理器继续工作。
- 发布版 1.0.6 经本地签名通道下载并切换到候选包。升级和回退后均从同一个会话编号读取旧历史，并用保存的 DPAPI 凭据发起真实的本地模型请求。配置和凭据文件逐字节一致，篡改清单在下载前被拒绝。候选 ZIP 也通过默认稳定通道引导完成全新安装，复用已验签的下载。
- 便携版与受管版的 15 项检查通过，覆盖中文及长路径、PowerShell 和 CMD 入口、损坏包、哈希正确但无法启动的包、配置备份、重复安装、占用退出，以及卸载时保留用户数据和非受管目录。
- 维护矩阵的 9 项检查通过。升级时保持 CLI 和原生模型配置进程的版本占用，进程退出后允许清理。修复使用新的物理目录，回退后管理器可继续使用，隔离安装卸载成功。

初次把发布版 1.0.6 安装到工作树的深层目录时，内置工具探测失败。复验使用 Windows 临时目录中的中文路径完成。候选包单独通过长路径安装和启动，公开 1.0.6 则通过临时目录中的真实在线安装。
