# 第四阶段交付报告

版本：0.0.4-phase4。日期：2026-10-29。

## 交付结果

主控协作已接入正式 `emergence`，可用一个主控向多个执行窗口真实派发、排队、等待依赖和收取结果。独立与协作模式共用已有会话，每个执行窗口保留自己的项目和模型。

- `/mode collaborate <主控> <执行者...>` 选择角色，`/mode independent` 切回独立模式；切换保留历史，运行任务继续，队列按模式暂停/恢复。
- 主控工具为 `emergence_dispatch`、`emergence_tasks` 和 `emergence_wait`；执行者用 `emergence_report` 报告结果。工具在相应会话中按角色启用，执行时再次检查权限与暂停状态。
- 任务记录包含稳定 ID、请求去重标识、发起/执行会话、目录、模型、目标、依赖、进度、状态、补充指令和结果日志范围。接受和派发意图先持久化，再向执行者投递。
- 排队项可以单独取消，运行任务可以补充指令、取消或人工接管；接管暂停该执行者后续队列，释放后继续。暂停派发与取消运行分别实现。
- F4 或 `/tasks` 查看实时任务列表，`/task show <id>` 查看完整目标、摘要和错误。后台问卷、审批和通知不抢焦点。
- 可创建 Git worktree 隔离修改，并通过用户命令 `/integrate <源窗口>` 整合同仓库已提交成果。冲突保留现场并记录；源任务未通过时不会把整合结果标为验证成功。

## 状态与执行证据

调度不以“Agent 空闲”或模型文字判定成功。任务使用持久化消息 ID 关联 Harness 的 inbox claim，取得准确 turn，再按对应 `turn/end`、`tool/result` 和执行者报告结算。其他用户输入或后续任务的结果不能归到前一项任务。

工具失败或缺少报告会进入“待检查”；模型请求失败、明确失败报告进入失败；取消、依赖阻塞和中断有独立状态。PowerShell 即使工具传输成功，也会检查 `tools/result` 的结构化 canonical value 中的退出码、超时、信号和后台状态，并把证据持久化。没有通过屏幕字符串或模型成功摘要决定任务状态。

正常结束且有明确报告、没有已观察到的工具/命令失败才标完成。该状态不等于代码语义正确，测试命令、产物内容和成果整合仍要结合实际证据审查。

任务回执保存后送给原主控：协作模式中唤醒空闲主控，运行中的主控在下一步获得上下文；独立/暂停模式不自动唤醒。回执标记先保存，崩溃窗口可能漏一次实时提示，账本和会话日志仍可查询，不会通过重放任务来补通知。

## DeepSeek 实网协作验收

已使用用户配置的加密凭据，运行一个真实 DeepSeek Flash 主控和两个执行窗口。主控实际调用两次 `emergence_dispatch`，执行者在各自项目中调用 `write`、`read` 和 `emergence_report`；两个文件内容均已核对，主控调用 `emergence_wait` 接收结果，并观察到任务回执。

这是显式、有界的实网验收；故障、取消和冲突测试使用本地模型服务控制响应，实际执行 Harness、文件和命令工具。默认自动巡检不会重复收费调用。见 [实网记录](../../artifacts/phase4/live-deepseek.json)。第二家真实供应商仍未验证。

## 持久化与边界

旧的第三阶段布局可直接读取。任务和整合记录与布局原子保存；重启保留角色及记录，进入独立模式，未完成/排队任务标为中断。需要时以新请求显式派发，不自动重试可能产生副作用的工作。处于合并中的整合记录恢复为待检查，不自动执行 Git merge。

同一工作台最多 16 个窗口、500 项任务、100 项整合记录；任务列表展示最近 80 项摘要。共享目录保护仍只覆盖工作台内部 `write/edit` 的重叠修改，不能覆盖 shell/MCP、外部编辑器或先后发生的过期覆盖。Git 整合只合并同仓库干净工作树中的提交，不自动测试、解决冲突、stash 或 reset。

当前优先原生 Windows/PowerShell。ConPTY 不覆盖物理中文输入法、系统剪贴板和字体人工检查。专用测试驱动在确认应用和 shell 已退出后显式结束，绕过 node-pty conout worker 保留；不宣称全部测试资源自然回收。多终端同时打开同一工作台、长期压力及独立发布包仍在后续阶段。

## 快速体验

```text
emergence
```

F2/F3 开出三个窗口，输入 `/mode collaborate 1 2 3`，然后在主控中描述任务。F4 查看任务，`/takeover 2` 接管，`/release 2` 归还，`/mode independent` 切回独立操作。详见 [应用使用说明](../../emergence/README.md)。
