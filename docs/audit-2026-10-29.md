## 修复的问题

1. **子代理的命令确认归属。** 旧处理只匹配窗口本身的会话 ID，子代理可能绕过本地命令确认。现在按照真实运行时父子关系找到所属窗口，嵌套子代理的审批和问卷送到该窗口；无法归属的本地 shell 调用拒绝执行。伪造持久化父会话字段不能取得权限。测试分别覆盖拒绝、允许和无所属窗口的调用。
2. **跨进程重复恢复和配置串用。** 同项目工作台、窗口会话及所属子代理加入 OS IPC 租约，防止两进程同时写同一份会话历史和布局。不同项目仍可并行。运行时 profile 每次启动独立生成并清理，不再由不同实例覆盖同一个启动配置。已验证正常退出和进程终止后的释放、跨项目路径恢复同一会话的拒绝。
3. **延迟回执投递到新会话。** 旧代码检查主控归属后等待持久化，期间可以换会话。现在在实际投递前重新检查窗口、控制器、会话和关闭状态，延迟回执不会唤醒替换后的会话。
4. **共享配置和凭据并发覆盖。** 配置新增和凭据更新加跨进程互斥，读取与修改发生在同一保护范围；凭据临时文件使用独立 UUID。窗口 `/model` 不再把旧配置快照回写到共享配置，外部新增的模型配置不会被覆盖。
5. **子代理失败被父任务的成功摘要掩盖。** 命令结构化退出状态和子代理工具失败按真实所属窗口进入任务证据；子代理未结束时不能确认成功。相关回归要求父任务即使提交成功报告，子代理非零退出仍使任务进入待检查。
6. **文件修改冲突归属。** 窗口与子代理使用实际执行目录规范化文件路径；不同 Agent 的重叠同文件修改都参与冲突检查，包含同一窗口下的子代理。
7. **超长草稿导致持久化失败。** 输入超过 100000 字符时保留可保存的前缀并提示，不截断 emoji 代理对，避免布局保存和退出连续失败。
8. **诊断输出的控制序列和凭据脱敏。** 清理终端标题/剪贴板等控制序列；自定义凭据环境变量即使名字没有 KEY/TOKEN 也会按配置脱敏。
9. **关闭过程的重复调用和资源顺序。** 会话关闭复用同一收尾 Promise，先拒绝新工作，再停止运行时，最后释放租约与监听器，避免关闭时又接收新工作。
10. **测试同步问题。** 全量检查发现整合测试偶发在主控处理回执时立即执行合并；真实产品正确拒绝忙碌窗口。测试改为暂停派发并等窗口空闲，保留产品的保护条件。

## 运行时与依赖安全

项目自带运行时从 Node 26.4.0 升级到 **26.13.0 LTS**，包含本月安全修复；没有改动系统 Node。新二进制 SHA256 与官方发布清单一致。最低运行要求提高为 26.12.1，缺少项目运行时且系统版本过旧时明确拒绝启动。[Node 安全公告](https://nodejs.org/en/blog/vulnerability/october-2026-security-releases)、[26.13.0 发布与校验值](https://nodejs.org/en/blog/release/v26.13.0)。

初始 npm 审计标记 213 个受影响依赖条目，包含传递依赖传播，并非 213 个独立漏洞。定位到以下五类依赖，升级并固定修补版本后，重新审计为 0。

| 依赖 | 修补版本 | 公告 |
| --- | --- | --- |
| Zod | 4.6.6，包含 Harness 的传递依赖覆盖 | [资源耗尽](https://github.com/advisories/GHSA-mrhx-c7xc-m3w5) |
| lodash-es | 4.18.1 | [模板代码注入](https://github.com/advisories/GHSA-r5fr-rjxr-66jc) |
| Undici | 8.12.2；Node 内置版本也已更新 | [TLS 选项处理](https://github.com/advisories/GHSA-2m5v-pch6-74hx) |

## 凭据与验证边界

Windows DPAPI 当前用户加密存储及显式环境变量优先级保持有效。扫描覆盖应用源码、构建产物、文档、各阶段产物和涌现配置目录，使用本机已加密配置的真实凭据作精确匹配，没有输出其值。原始用户密钥文件、第三方依赖目录和原始压缩包不属于此次明文扫描范围。见 [凭据检查](../artifacts/audit-2026-10-29/credential-check.json)。

本轮模型故障场景使用本地 HTTP/SSE 服务，实际运行正式 Harness 和工具，没有重复收费调用。真实 DeepSeek 协作证据沿用[第四阶段实网记录](../artifacts/phase4/live-deepseek.json)。另一真实供应商仍待补验。

默认 ask-local 会在本机执行经确认的命令，文件工具和第三方扩展仍有本机访问能力，不是系统隔离沙箱。不要把密钥填进聊天或让工具输出密钥；Harness 原始事件会保留用户和工具提供的内容，工程扫描为零不代表任意未来任务的原始日志都不可能含敏感内容。

短时并发不等于长时间压力或无内存泄漏证明。物理中文输入法、系统剪贴板、字体、其他终端和 macOS/Linux IPC 租约仍需后续实测。node-pty 专用驱动继续在确认应用和 shell 退出后显式结束，不据此宣称全部测试资源自然回收。
