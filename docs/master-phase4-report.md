日期：2026-10-30。本阶段复用既有主控、KIM 规划、Collaboration 调度、任务侧栏和权限审批，不新增调度器，不改变主题、Logo 或原生模型配置工具。

## 可直接使用的交互

- 顶栏新增一行主控协调状态。理解目标、组织分工、等待执行、核对验收、修复、待确认、暂停、取消、受阻和完成，均从实际协调记录投影，不显示猜测的进度百分比。
- 点击该行打开总任务详情：目标、阻塞原因、分工、中文职责、分配原因、项目、模型配置、依赖状态、预算和最终验收回执。窗口使用界面编号并保留内部 ID，便于对应。
- 点击“暂停 / 继续”控制既有派发器。暂停停止新的派发与跟进，已开始调用可能继续完成；继续不复活取消或受阻的任务。说明在总任务页可见。
- 点击“待确认 N”揭示并进入真实等待回答的窗口，不批准操作、不代答问题；跳转前核对窗口、会话和请求 ID。
- 子任务详情保留原有日志、产物和证据，并补充所属总目标、分配原因和“接管 / 交回”。右键菜单也提供接管与总任务入口，可用滚轮浏览完整菜单。接管遵循原语义：停止该窗口当前协作任务；交回不重放已取消工作。
- 宽屏沿用侧栏，窄屏沿用任务页；查看、暂停、接管和切换不提交聊天草稿。总任务详情只读取本地事实，不触发模型请求。普通协调通知仍收起呈现，详细证据留在任务侧栏和日志。
