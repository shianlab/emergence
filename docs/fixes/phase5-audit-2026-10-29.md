# 第五阶段整体复查与修复

时间：2026-10-29。检查起点：0.0.5-phase5；修复版本：**0.0.5-phase5.1**。

本轮先运行原有 30 项自动测试，全部通过；随后复查生命周期、异步配置、模板及代理归属，新增测试复现了 **8 个此前未覆盖的边界问题**。已修复并加入默认巡检。

## 已复现并修复

| 问题 | 触发与影响 | 修复 |
| --- | --- | --- |
| MCP 启动和关闭竞态 | 服务尚未连接完成时关闭，原实现没有跟踪启动中的实例；关闭返回后仍可能注册工具 | 从启动起登记实例，关闭中止并等待启动结算，禁止关闭后再启用 |
| 异步配置期间仍接受新工作 | 慢速 MCP/权限等配置更新尚未结束，其他窗口可开始任务、分屏或关闭，可能观察半完成的能力状态 | 运行能力更新期间暂停接受新任务及会话结构变更，结束后恢复；现有审批回答和退出仍可处理 |
| 模板协作角色被焦点覆盖 | 从执行窗口输入无参数 `/mode collaborate`，错误地把它设为主控 | 优先沿用模板/已保存的主控和执行者，显式编号仍可修改 |
| 子代理扩展工具使用主会话绑定 | 子代理在另一目录、另一模型执行，扩展得到的却是主会话目录、模型和会话 ID | 传递实际调用代理的 workingDirectory、模型路由和会话身份 |
| 等待中的扩展命令无法在界面停用 | `/extensions disable` 要求扩展已空闲，无法用该命令中止长时间等待的扩展命令 | 停用走协作式取消，移除入口、释放资源并等待在途回调退出 |
| 图片历史兼容检查不完整 | 只检查用户/模型消息，遗漏工具返回的图片和待处理上下文中的图片 | 检查工具结果及 Inbox 图片，拒绝不兼容切换；已经标记 offloaded 的图片按文本处理 |
| 异步扩展面板阻塞停用设置 | 面板渲染占住设置操作标记，另一窗口无法停用它 | 面板读取与设置更新分开；停用信号能够中止等待，晚到结果不覆盖其他会话 |
| 子代理能力限制错用主会话模型 | 主模型允许工具、子模型声明不支持工具时，子代理仍可执行工具 | 最终执行 guard 和预执行策略均按实际代理模型检查，窗口权限规则继续有效 |

新增自动测试：`emergence/tests/audit-phase5.test.ts`。这 8 项测试均先在原实现失败，再在修复后通过。

另补充原生界面回归：模板提交后立即刷新会话绑定，重置旧编辑器的滚动/选择状态。在故意放慢旧会话释放、同时运行真实渲染帧时，新会话不会被写回旧草稿；原草稿仍在模板切换备份中。验证脚本：`emergence/tests/audit-template-ui.ts`。
