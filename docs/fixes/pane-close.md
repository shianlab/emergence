# 窗口关闭修复

版本：0.0.4-phase4.1。日期：2026-10-29。

原来只有 `/terminate` 能释放窗口，界面缺少明显入口；只剩一个可见窗口时，即使仍有隐藏窗口，也会拒绝关闭。

现在支持 F6、标题栏 `[关闭]` 和 `/close [编号或ID]`。关闭停止相关任务并释放会话，从持久化布局移除窗口，保留已保存的会话历史。最后一个可见窗口关闭后，会自动显示隐藏窗口接替。整个工作台至少保留一个窗口，退出使用 Ctrl+C 或 `/exit`。

关闭执行窗口会取消它正在执行和排队的协作任务，其他执行窗口继续。关闭主控按原策略取消其关联任务，并切回独立模式；不再向正在关闭的主控投递唤醒通知。并发关闭保留至少一个可用窗口。F8 仍只隐藏，任务继续。

已通过 14 项自动回归，以及 8 项真实 Windows ConPTY 关闭检查：入口可见、F6 取消隔离、隐藏窗口接替、鼠标关闭非焦点且等待问卷的窗口、最后窗口退出提示、指定后台窗口关闭、重启不恢复已关闭窗口、正常退出。原工具链、多窗口和主控协作也纳入回归。
