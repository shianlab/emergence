2. 历史规划文档包含个人下载路径，已替换为文件名并保留 ZIP 来源哈希；测试假密钥不做误删。
3. 已有恢复测试覆盖 legacy、fence、crash，但没有直接构造“布局成功、台账待审查”的矛盾；本阶段补上明确行为断言，避免第二阶段迁移破坏恢复优先级。
