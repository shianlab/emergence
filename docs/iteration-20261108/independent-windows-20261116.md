# 多窗口改为独立会话（2026-11-16）

按用户决定退出主控/协同功能，不继续修复或启用此前的跨窗口派活。

## 当前行为

- 保留多窗口、分屏、切换、关闭、隐藏/显示、最大化、不同项目和不同模型、各自草稿与历史。
- 右键菜单只提供窗口操作；移除设置主控、红框角色标识、角色偏好、接管/交回和团队派工入口。
- `/mode`、`/assign`、`/assign-role`、`/team`、`/window-role`、`/dispatch`、`/takeover`、`/release` 明确提示功能已移除，不转发给模型。
- 正式工作台执行范围固定为 `session`。能力清单只列当前窗口；跨窗口派发工具不注册。直接调用跨窗任务、跨窗执行图、主控配置和隐式审查开窗也会被运行层拒绝，没有用户配置开关恢复协作。
- 保留单会话 KIM、原生子代理、编程/数据、权限、记忆、Skills/MCP、命令执行和检查回执。`/audit show/history` 可读旧证据，跨窗 `/audit run` 不再可用。
- 模型配置插件移除主/副窗口默认选项，保留全局、新窗口和按编号分配。旧角色默认值不再用于决定窗口角色，不删除现有模型或加密凭据。

## 兼容与代码边界

旧布局、会话、草稿和任务事实继续保留。恢复时清除主控、执行、接管及窗口角色偏好，未结束任务按原恢复流程中断，不能重放。旧模板忽略角色关系，只恢复项目、模型和布局。

没有删除整套任务引擎：单窗口计划、已有证据和历史台账仍依赖它。正式入口由统一执行范围约束；历史契约、审批、恢复和证据回归使用 `tests/fixtures/historical-orchestration.ts` 中的测试宿主。该宿主不进入产品，也不代表协同功能仍然开放。保留这些回归是为了维护旧记录及共用引擎的安全边界。

README、项目约定和模型运行身份已同步。未改用户项目文件、API 密钥、Skills/MCP 配置或个人会话内容。保留另一个 UI 工作窗口的最新改动。

## 使用

退出旧版 Emergence 后重新输入 `emergence` 即可使用。无需重新安装，也不需要重新输入模型密钥。已打开的旧进程不会热更新；旧模型配置窗口也需关闭后重新打开。
